# CSHShydRology 1.5.0

-  functions from the packages `terra` and `tidyterra` have replaced `raster`, which is deprecated,
in the catchment delineation functions
-  added a test suite covering most exported functions, raising test coverage from
7% to roughly 94%, together with a `test-coverage` GitHub Action and a Codecov badge.
Tests that need the WhiteboxTools executable, a HYDAT database or network access are
skipped when those are unavailable rather than failing
-  small reproducible sample data files for the ECDE and AHCCD file readers are now
kept in `tests/testthat/fixtures/`, generated by `data-raw/make_test_fixtures.R`, so
those readers can be tested without downloading anything
-  fixed `ch_read_AHCCD_monthly` so that minimum temperature (`mn`) files can be read
at all; the variable name was assigned to the wrong object
-  fixed `ch_get_url_data` so that an already-downloaded `.tif` is read from disk
instead of failing with "object 'result' not found"
-  fixed `ch_tidyhydat_ECDE_meta` so that `all_ECDE = TRUE` works for a single station
-  fixed the median returned by `ch_circ_mean_reg`, which was reported in degrees and
taken from a circular median that can return the opposite direction
-  fixed `ch_get_peaks` so that records containing missing flows no longer cause an error
-  fixed argument checks in `ch_wbt_channels` and `ch_wbt_catchment_onestep` that called
`stats::step()` instead of `stop()`, and stopped `ch_wbt_catchment_onestep` writing the
channel network over the catchment polygon file
-  `ch_polar_plot_peaks` now restores the graphics parameters it changes
-  corrected out-of-date documentation in a number of functions, and restored the
`Floodnet_functions` help page, which was missing entirely

# CSHShydRology 1.4.4

-   changes to hydrograph plotting functions, including adding `ch_gg_hydrographs` which creates **ggplot2** objects
-   removal of function `ch_flow_raster_trend` as it used the package **Kendal**, which will be archived by CRAN

# CSHShydRology 1.4.3

-   added functions ch_high_Grubbs_test and ch_ffa_screen_plot to identify outliers when fitting distributions to mean daily streamflows
-   updated urls to specify https instead of http

# CSHShydRology 1.4.2

-   minor fixes to return statements in `ch_tr_sign` and `ch_tr_signif`
-   fixed some URLs which redirect to other locations
-   removed functions `ch_get_map_base` and `ch_map_plot_data` as we could not trap the error resulting from accessing the server. We hope to be able to restore these functions in the future.
